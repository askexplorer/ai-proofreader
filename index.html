🔧 Workspace setup (admin, one time)

Not set up

Gives your team personal accounts, one shared list of reviews with layout progress, one shared API key, and password-protected links for outside translators. About 10 minutes, once, using a free Supabase project. Colleagues do not do any of this.

Create a free Supabase project

  1. Go to supabase.com/dashboard and sign in with an Explorer-owned account.
  2. Click New project, give it a name (for example explorer-team), pick a region close to your team, set a database password and press Create.

Close public sign-up and create your account

  1. In Supabase open Authentication → Sign In / Providers and turn off Allow new users to sign up (recommended). Even if it stays on, the portal only lets in people you add as team members.
  2. Open Authentication → Users → Add user → Create new user. Use the email yourname@explorer.team (any email works), type a password, and tick Auto Confirm User. Do this for yourself first; add colleagues later.

Run the setup SQL (one time)

  1. Click Copy setup SQL below (it makes the account from step 2 the admin).
  2. In Supabase open SQL Editor → New query, paste, and press Run. You should see Success.

This creates locked tables. Nobody can read them directly: every action is checked against the signed-in account, and reports are encrypted in the browser.

Connect this portal and sign in

In Supabase open Project Settings → API and copy the Project URL and the anon / publishable key. That key is public by design, so it is safe to paste here.

ℹ️ About

Checks for Typos, Spelling, Grammar, Punctuation, Capitalization, Style, Consistency, Clarity, and Factual errors. Query severity flags ambiguous items for author review. Supports PDF (single-page & double-page spread), Word (.docx), InDesign (.idml — direct from source, no extraction artifacts), plain text, paste, and batch upload. Models: Claude Sonnet/Opus/Haiku (Anthropic) and GPT-4o / GPT-4o mini (OpenAI). Multi-language: Arabic, Hebrew, Persian (RTL), Bengali, Hindi, Tamil, Thai, Japanese, Korean and all major Latin-script languages. Exports: PDF, Word, corrected document, shareable HTML, JSON. Translation check: add the original under “Compare with a source document” to check a translation for missing or added text, wrong meaning and wrong numbers, with a score and a list for the translator.
